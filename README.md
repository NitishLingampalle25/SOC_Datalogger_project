# Secure SoC Data Logger for Mission-Critical Telemetry

An open-source, hardware-accelerated System-on-Chip (SoC) peripheral architecture designed for secure, tamper-proof event logging in safety-critical cyber-physical systems (such as railway signaling, TCAS, automotive black boxes, and industrial SCADA). 

The platform integrates a hardware-accelerated cryptographic engine, autonomous DMA-based logging, system integrity watchdog supervision, and standard AMBA AXI/AHB bus interconnects to ensure zero telemetry data loss and real-time cryptographic attestation.
